# «Связано» — сайт вязаных игрушек на Cloudflare Workers (бесплатно)

Каталог вязаных игрушек, страница поддержки (клиент ждёт ответ на странице), админ-панель `/admin`
(игрушки с несколькими фото и галереей, обращения, контакты Telegram/MAX/VK, сведения о продавце и правовые страницы) и страницы для соответствия законодательству РФ.
Работает на бесплатном тарифе Cloudflare, без своего домена — по адресу вида `https://vyazanye-igrushki.<ваш-поддомен>.workers.dev`.

## Структура проекта
```
wrangler.jsonc            настройки платформы (имя сайта, база D1, статические файлы)
src/index.js              точка входа воркера: маршрутизация, защитные заголовки
src/routes/public.js      API каталога и обращений клиентов, выдача фото
src/routes/admin.js       вход, обращения, игрушки, загрузка фото, настройки
src/lib/                  util (ответы, проверка данных) · crypto (хеши, AES) · db (схема, лимиты) · validate
public/                   сайт: index.html, app.js, style.css; админка: admin.html, admin.js; _headers (защитные заголовки)
test/                     автотесты (npm test) и локальный сервер для проверок
docs/                     инструкции
```

## Для разработчика
```
npm install
cp .dev.vars.example .dev.vars   # впишите логин, пароль (14+ символов) и APP_SECRET (32+ символа)
npm run dev                      # локальный сайт на http://localhost:8787
npm test                         # 63 автоматические проверки
```
Требуется Node.js 22.13+. Данные хранятся в Cloudflare D1; таблицы создаются автоматически.

## Обновление «Связано» (октябрь 2026)

- Розово-белый дизайн по присланному референсу, название «Связано».
- Галерея до 8 фотографий на одну игрушку; листание стрелками и миниатюры.
- Ссылки на Telegram, MAX и ВКонтакте в настройках контактов.
- Термины «Срок изготовления» и «Получите заказ».
- Загрузка крупных фото с автоматическим уменьшением; изображения отображаются через `object-fit: contain`.
- Запросы обновляются без браузерного кеша, обновление переписки и админ-списка ускорено.
- Миграция поля `images` выполняется автоматически для существующей D1-базы.

Важно: правовая страница описывает текущую логику сайта, но не является гарантией юридического соответствия для любого продавца. Перед сбором персональных данных и продажей детских игрушек проверьте требования к локализации данных, трансграничной передаче, сведениям продавца и обязательному подтверждению соответствия изделий.


## Дополнительные возможности
- Логотип «Связано» в шапке и favicon (`public/logo.svg`).
- Публичный каталог без корзины, оплаты и оформления заказов; покупатель может открыть карточку игрушки и связаться с мастером.
- В админ-панели добавлены вкладки «Заказы» и «Статус / ошибки».
- В отчёте статуса проверяются D1, секреты, объёмы каталога, изображений, обращений и заказов; показывается журнал непредвиденных серверных ошибок.
- В переписке поддержки пустые и null-сообщения не отображаются.

**Важное перед публикацией:** сайт работает как каталог и не принимает оплату или заказы. Форма поддержки по умолчанию не принимает телефон и электронную почту в тексте. Если вы включите сбор контактов, аналитику или интеграции, заново проверьте применимые требования законодательства о персональных данных.


## Режим каталога без заказов

Публичная часть показывает каталог игрушек, фотографии, описание, стоимость, сроки изготовления и контакты. Корзина, оформление заказа и API создания заказов отключены. Покупатель может задать вопрос через поддержку или связаться с мастером через опубликованные контакты.

Политику конфиденциальности не следует удалять автоматически: хостинг обрабатывает технические данные запросов, а форма поддержки и внешние каналы связи могут иметь собственные правила обработки данных. Политика должна описывать фактические процессы сайта.
